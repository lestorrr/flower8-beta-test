# Flower8 Beta Test

Test versions of **Flower8**, a private app for couples, before everyone
else gets them. A beta is a test version, so it may have small bugs.

This repository holds only beta APKs, not code. Normal Flower8 releases are
in [flower8-releases](https://github.com/lestorrr/flower8-releases).

## Install

1. Open the [latest beta](https://github.com/lestorrr/flower8-beta-test/releases/latest)
   on your phone and download the `.apk`.
2. Open it. Android asks once to allow installs from your browser or file
   manager. Allow it, then tap **Install**.

A beta installs over Flower8: your account, chats and settings stay. After
that, new betas show inside the app as a **Beta update** in
**Profile → About**.

## Going back to normal updates

Turn off **Beta test updates** in **Profile → About**. The app then offers
only normal releases, and you get the next one as soon as it is newer than
your beta.

## Is this the real Flower8?

Every beta is signed with the same key as the normal releases. Android
refuses an update signed with any other key, so a changed APK can never
replace the app you have. To check a download yourself, its signing
certificate must match:

```

```
